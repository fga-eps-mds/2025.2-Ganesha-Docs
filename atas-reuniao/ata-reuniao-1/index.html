    🎯 Objetivos e Decisões

    A reunião foi focada na definição da arquitetura e na configuração do ambiente inicial do projeto para que o desenvolvimento possa ser iniciado.

    Área Decisão/Definição
    Arquitetura Arquitetura padrão MVC (Model-View-Controller).
    Linguagens/Frameworks Backend: Python (Flask), MySQL.
    Frontend: HTML/CSS, JavaScript (React).
    Controle de Versão Uso do Gitflow para gerenciamento de branches e Conventional Commits para mensagens de commit.
