# 🚀 DOCUMENTO DE VISÃO DO PRODUTO (GRANA ZERO)

## 1. Declaração de Posição do Produto

| Categoria | Detalhe |
| :--- | :--- |
| **Para:** | Estudantes Universitários |
| **Cujo:** | Tem dificuldade em organização financeira a nível de rastreamento e visualização de gastos, além de classificação dos mesmos. |
| **O Saldo Zero:** | É uma Aplicação Web (site) |
| **Que:** | Facilita a organização das finanças |
| **Diferentemente da:** | Planilhas (Excel/Google Sheets) e Grana Zen |
| **O Nosso Produto:** | Gera gráficos de forma automática, poupando o usuário do trabalho manual de criá-los como em planilhas, e oferece como principal diferencial a gestão financeira compartilhada, de forma simples e gratuita. |

## 3. Objetivos de Negócio (Atividade 3)

Os principais objetivos de negócio focam em:

* Metas e Planejamento
* Controle de Finanças
* Interface amigável
* Histórico de finanças
* Construção de Gráficos
* Responsividade
* Ciclo de Finanças
* Registrar despesas e receitas
* Poucos clicks para acessar funcionalidades
* Compartilhamento da finança
